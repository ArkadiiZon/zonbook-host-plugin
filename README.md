# Zonbook Host plugin for Claude

Marketplace for the [Zonbook Host](https://zonbook.com/en/ai-assistants) plugin: connect Claude to your Zonbook hosting
account and use ready-made skills for your daily brief, guest replies, check-in readiness, calendar and prices,
cleaning schedule and owner summaries.

```
/plugin marketplace add ArkadiiZon/zonbook-host-plugin
/plugin install zonbook-host@zonbook
```

Details, permissions and privacy: [plugins/zonbook-host/README.md](plugins/zonbook-host/README.md).
